# Pi v0.3.0

本版收口并发布 Migration v2，同时提供配套 pi-layout 迁移命令。

- `Migrate/MigrateContext`、`migration.Run` 返回 Result/error；保留旧 UP，新增 UpContext、Name、target、dry-run、plan/status。
- SQL / Redis 精确状态与可选租约锁，legacy 状态明确标识为推断结果；检测迁移 gap。
- 用户 panic、失败、取消均进入事务清理；错误包含 version/op/cause，保留部分成功结果。
- SQL Begin 使用 caller context；新增一次性 `sql.OpenContext`，命令可显式拥有和关闭连接。
- 修复 PostgreSQL 连接串空值/特殊字符转义，区分 SQL 锁占用与后端故障。
- pi-layout 提供 up/plan/status、默认加锁、超时、JSON 摘要、信号取消与非零失败退出码，不启动无关服务。
- CLI migration 模板使用 Name/UpContext；框架与 CLI 版本统一为 v0.3.0。

兼容性：旧 `app.Migrate(defs)` 语句仍编译但应处理返回值；旧 `migration.Run(defs, c)`
必须增加 ctx 参数。旧函数值/接口签名和无字段名结构体字面量需要调整。
原迁移存储和锁键保持 Kite 名称。详见[契约](../design/migration-v2.zh-CN.md)。

本版没有 down、checksum/history、锁续租、schema diff 或跨库原子事务。
MySQL DDL、Redis EXEC 和跨后端提交可能部分成功；错误后必须检查实际状态。
自带 layout 业务 DDL 仍以 SQLite 为准。完整构造/后台资源重构留在 v0.4.0。

验收覆盖 SQLite、MySQL、PostgreSQL、Redis，双进程锁竞争、panic/取消/失败清理、
迁移命令和 CLI 生成消费。详情见[验收记录](../verification/v0.3.0.zh-CN.md)。
