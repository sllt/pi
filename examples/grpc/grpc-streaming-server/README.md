# GRPC Server Example

This Pi example showcases a basic gRPC streaming server implementation. For detailed instructions on setting up gRPC handlers with Pi’s context support—enabling built-in tracing and database integration within your gRPC handlers—please refer to our [official documentation](https://github.com/sllt/pi/docs/advanced-guide/grpc).

### To run the example use the command below:
```console
go run main.go
```
